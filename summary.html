Free Claude Code - Usage & Optimization Guide

This guide summarizes how to use the Free Claude Code proxy, optimize its performance, and use it with Claude extensions or applications.

🚀 Quick Start

  1. Install: Use the platform-specific installer (PowerShell on Windows, curl|sh on macOS/Linux).
  2. Start the proxy: Run fcc-server in your terminal.
  3. Configure a provider: Open the Admin UI (http://127.0.0.1:8082/admin) and add your API key for a provider (e.g., NVIDIA NIM).
  4. Run Claude Code: Execute fcc-claude to launch Claude Code configured to use the local proxy.

🔧 Connecting Claude Code Clients

The proxy provides an Anthropic-compatible API at http://localhost:8082 (or your configured port) with auth token freecc. Configure any Claude Code compatible client:

1. Claude Code CLI (Recommended)

Use the provided launcher:

fcc-claude

This automatically sets:

  • ANTHROPIC_BASE_URL=http://localhost:8082
  • ANTHROPIC_AUTH_TOKEN=freecc
  • CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1
  • CLAUDE_CODE_AUTO_COMPACT_WINDOW=190000

2. VS Code Extension

Add to your settings.json:


"claudeCode.environmentVariables": [
  { "name": "ANTHROPIC_BASE_URL", "value": "http://localhost:8082" },
  { "name": "ANTHROPIC_AUTH_TOKEN", "value": "freecc" },
  { "name": "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY", "value": "1" },
  { "name": "CLAUDE_CODE_AUTO_COMPACT_WINDOW", "value": "190000" }
]

Reload the extension. If prompted to log in, choose the Anthropic Console path; the proxy handles traffic after env vars are active.

3. JetBrains ACP

Edit the installed Claude ACP config:

  • Windows: C:\Users\%USERNAME%\AppData\Roaming\JetBrains\acp-agents\installed.json
  • Linux/macOS: ~/.jetbrains/acp.json

Set for acp.registry.claude-acp:


"env": {
  "ANTHROPIC_BASE_URL": "http://localhost:8082",
  "ANTHROPIC_AUTH_TOKEN": "freecc",
  "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
  "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "190000"
}

Restart the IDE.

⚡ Optimization Tips

Per‑Model Routing: Set MODEL_OPUS, MODEL_SONNET, and MODEL_HAIKU in the Admin UI to route each Claude model tier to different providers (e.g., Opus to a powerful model, Sonnet/Haiku to faster/cheaper ones). Leave a tier blank to inherit MODEL.
Auto‑Compaction Window: The launcher sets CLAUDE_CODE_AUTO_COMPACT_WINDOW=190000 to reduce token usage by compacting long conversations. Adjust in the Admin UI if needed.
Local Request Optimizations: The proxy answers trivial Claude Code probes (like token counting, model listing) locally, saving latency and provider quota. Ensure the Admin UI is configured and running.
Streaming & Tool Use: The proxy supports streaming, tool use, and thinking blocks. For providers that lack native streaming (e.g., some OpenAI‑compatible endpoints), the adapter translates OpenAI chat streaming into Anthropic SSE.
Provider‑Specific Notes:
  • For Gemini, use the gemini/ prefix (e.g., gemini/gemini-2.5-flash).
  • For DeepSeek, use the deepseek/ prefix; it uses the Anthropic‑compatible endpoint.
  • For local providers (LM Studio, llama.cpp, Ollama), ensure the server is running and the base URL is set correctly in the Admin UI.

🔌 Optional Integrations

Enhance your setup with:

  • Discord/Telegram Bots: Run Claude Code sessions remotely via chat. Configure in Admin UI → Messaging.
  • Voice Notes: Transcribe voice input via local Whisper or NVIDIA NIM Riva gRPC. Install with --voice-local or --voice-nim flags, then enable in Admin UI → Messaging → Voice.

🧩 Can I Use This in Claude Extension or Application?

Yes. Free Claude Code is designed to work as a drop‑in Anthropic‑compatible proxy for any Claude Code‑compatible client, including:

  • VS Code extension (via environment variables as shown above)
  • JetBrains AI Assistant / ACP (via env vars in the agent config)
  • Custom applications that set ANTHROPIC_BASE_URL and ANTHROPIC_AUTH_TOKEN to point at the proxy
  • Any tool that respects the Anthropic Messages API and accepts a custom base URL and auth token

Simply launch your Claude Code extension or application with the environment variables:


ANTHROPIC_BASE_URL=http://localhost:8082
ANTHROPIC_AUTH_TOKEN=freecc
CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1
CLAUDE_CODE_AUTO_COMPACT_WINDOW=190000

Then start the client. The proxy will handle all API traffic, model routing, streaming, tool use, and optimizations.
